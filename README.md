# Expense Tracker

A command-line expense tracker built with Python and SQLite, supporting multiple users on the same machine.

## Features
- Add expenses with category, description, amount, and date
- View all expenses for a user
- View total expenses
- View expenses grouped by category
- Multi-user support — each user's data is kept separate using SQLite queries filtered by username

## Tech Stack
- Python
- SQLite3 (via Python's built-in `sqlite3` module)

## How to Run
```bash
python main.py
```
